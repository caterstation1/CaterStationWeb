# CaterStation Prototype Lab

Static, isolated prototypes for three CaterStation design directions. No Shopify credentials, checkout, customer data or production theme edits are used.

## Run locally
```bash
cd /workspace/CaterStationWeb/prototype-lab
npm run dev
```
Open http://127.0.0.1:5173/.

## Routes
- `/` concept dashboard
- `/concept-one` Corporate Ordering Machine
- `/concept-two` Big Food Reveal
- `/concept-three` Build Your Feed
- `/comparison` scoring comparison

## Notes
This is a first-pass prototype lab. Interactions are simulated and intended for strategy/design review, not production checkout.
